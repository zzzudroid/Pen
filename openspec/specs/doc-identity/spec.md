# doc-identity Specification

## Purpose

Постоянный идентификатор документа, не зависящий от имени файла, чтобы ссылки и закладки переживали переименование, и безопасное поведение, когда цель ссылки недоступна.

## Requirements

### Requirement: Постоянный идентификатор документа
Каждый документ (тетрадь, доска) SHALL иметь постоянный идентификатор (UUID), записанный в `meta.json` и не меняющийся при переименовании и сохранении. Документ, у которого идентификатора нет (создан в формате v1 или v2), MUST получить его при первом сохранении после открытия.

#### Scenario: Переименование
- **WHEN** пользователь переименовывает тетрадь, на которую есть ссылка
- **THEN** идентификатор документа остаётся прежним, а ссылка по-прежнему открывает эту тетрадь

#### Scenario: Старая тетрадь
- **WHEN** пользователь открывает тетрадь формата v2 и вносит правку
- **THEN** после сохранения файл содержит идентификатор и открывается как раньше

### Requirement: Формат .pen версии 3
Приложение SHALL записывать новые и изменённые документы в формате v3: идентификатор документа, список ссылок и список закладок хранятся в `meta.json`. Файлы v1 и v2 MUST читаться без изменений; файл более новой версии MUST открываться с понятной ошибкой, а не портиться.

#### Scenario: Обратная совместимость
- **WHEN** пользователь открывает тетрадь, созданную до этого изменения
- **THEN** все штрихи и страницы на месте, список ссылок и закладок пуст

### Requirement: Поиск документа по идентификатору
Приложение SHALL находить документ в `Documents/Pen/` по идентификатору без чтения всех файлов целиком при каждом переходе: соответствие «идентификатор → файл» MUST храниться в индексе и обновляться инкрементально по времени изменения.

#### Scenario: Переход по ссылке после переименования
- **WHEN** документ переименован, а затем открыта ссылка на него
- **THEN** документ находится по идентификатору и открывается

### Requirement: Недоступная цель
Ссылка, цель которой не найдена (документ удалён или файл недоступен), MUST отображаться как «недоступна» и MUST NOT приводить к падению; тап по ней показывает сообщение, а пользователь может удалить такую ссылку.

#### Scenario: Документ удалён
- **WHEN** пользователь нажимает ссылку на удалённую тетрадь
- **THEN** появляется сообщение «Документ недоступен», приложение продолжает работать
