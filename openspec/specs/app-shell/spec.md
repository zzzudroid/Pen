# app-shell Specification

## Purpose

Базовая оболочка приложения Pen: запуск на планшете, навигация между экранами и сведения о сборке для проверки свежести установленного APK.

## Requirements

### Requirement: Запуск на целевом планшете
Приложение SHALL устанавливаться через `adb install` и запускаться на Xiaomi Pad 7 (Android 15) в альбомной и портретной ориентации.

#### Scenario: Первый запуск
- **WHEN** пользователь запускает установленное приложение
- **THEN** открывается главный экран с двумя половинами (слева заметки, справа холсты) и шапкой со ссылками «О программе», «Диагностика пера», «Холст» и «Поиск по рукописи»; список из пяти пунктов не показывается

#### Scenario: Поворот экрана
- **WHEN** пользователь поворачивает планшет
- **THEN** текущий экран перестраивается под ориентацию без потери состояния

### Requirement: Сведения о сборке
Экран «О программе» SHALL показывать название приложения, версию (versionName и versionCode), дату-время сборки APK, короткий git-хэш коммита и пометку о незакоммиченных изменениях; все значения проставляются автоматически при каждой сборке.

#### Scenario: Проверка свежести билда
- **WHEN** разработчик собирает и устанавливает новый APK и открывает «О программе»
- **THEN** показанное время сборки совпадает с моментом последней сборки с точностью до минуты, а хэш — с текущим коммитом

### Requirement: Сборка на Windows и Linux
Проект SHALL собираться одной командой Gradle Wrapper на Windows и Linux без правки файлов под репозиторием; машинно-зависимые пути MUST храниться только в неотслеживаемом `local.properties`.

#### Scenario: Сборка на чистой машине
- **WHEN** на машине с Android SDK репозиторий клонирован и создан `local.properties` с `sdk.dir`
- **THEN** команда сборки debug-APK завершается успешно
