# handwriting-search Specification

## Purpose

Поиск по рукописному содержимому тетрадей: распознавание русского текста на устройстве и быстрый поиск по страницам.

## Requirements

### Requirement: Распознавание рукописи
Приложение SHALL распознавать рукописный русский текст страниц тетрадей на устройстве. Страница разбивается на строки, каждая строка распознаётся отдельно. При первом использовании модель распознавания MUST скачиваться с отображением состояния; при недоступности (нет сети, нет сервисов Google) показывается понятное сообщение, приложение не падает.

#### Scenario: Первый запуск поиска
- **WHEN** пользователь впервые открывает «Поиск по рукописи» при наличии сети
- **THEN** видит загрузку модели, затем индексацию «N из M тетрадей»

#### Scenario: Нет сервисов Google
- **WHEN** распознавание недоступно на устройстве
- **THEN** экран сообщает причину, остальные разделы работают

### Requirement: Инкрементальный индекс
Распознанный текст SHALL храниться в индексе приложения по страницам. Обновление индекса MUST заново распознавать только тетради, изменённые с прошлой индексации, и удалять из индекса удалённые тетради.

#### Scenario: Правка одной тетради
- **WHEN** пользователь изменил одну тетрадь из десяти и обновил индекс
- **THEN** распознаётся только она

### Requirement: Поиск
Поиск SHALL находить страницы, на которых встречаются все слова запроса, без учёта регистра и различия «ё»/«е». Результат MUST показывать тетрадь, номер страницы и фрагмент распознанного текста с подсветкой совпадения. Выбор результата открывает тетрадь.

#### Scenario: Поиск слова
- **WHEN** пользователь ищет «интеграл», а на 3-й странице тетради «Матан» написано «Интеграл Римана»
- **THEN** в результатах есть «Матан · стр. 3» с подсвеченным словом

#### Scenario: Ё и е
- **WHEN** пользователь ищет «ещё», а в заметке распознано «еще»
- **THEN** страница находится
