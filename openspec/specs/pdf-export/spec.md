# pdf-export Specification

## Purpose

Автоматический векторный PDF рядом с каждой тетрадью: заметки можно открыть на любом ПК или отправить из приложения без ручного экспорта.

## Requirements

### Requirement: PDF рядом с тетрадью
Для каждой тетради `<имя>.pen` в `Documents/Pen/` приложение SHALL поддерживать файл `<имя>.pdf` с тем же содержимым. PDF MUST обновляться при каждом сохранении тетради, создаваться вместе с новой тетрадью, переименовываться и удаляться вместе с ней.

#### Scenario: Свежий PDF после правки
- **WHEN** пользователь дописал страницу и прошло автосохранение
- **THEN** `<имя>.pdf` содержит новый штрих

#### Scenario: Переименование и удаление
- **WHEN** пользователь переименовывает тетрадь, а затем удаляет её
- **THEN** PDF сначала получает новое имя, а затем удаляется вместе с `.pen`

### Requirement: Содержимое PDF
PDF SHALL содержать все страницы тетради в их порядке, в формате A4 (595×842 пт), с шаблоном страницы. Штрихи MUST экспортироваться векторными контурами с цветом и прозрачностью кисти.

#### Scenario: Увеличение на ПК
- **WHEN** пользователь открывает PDF на компьютере и увеличивает масштаб до 800%
- **THEN** линии остаются гладкими, без пикселей

#### Scenario: Выделитель
- **WHEN** на странице есть выделитель поверх текста ручкой
- **THEN** в PDF текст виден сквозь полупрозрачный выделитель

### Requirement: Отказоустойчивость экспорта
Запись PDF MUST быть атомарной. Ошибка экспорта PDF не SHALL мешать сохранению `.pen`; редактор показывает отдельный значок ошибки PDF.

#### Scenario: Ошибка экспорта
- **WHEN** запись PDF завершилась ошибкой
- **THEN** тетрадь `.pen` всё равно сохранена, и в редакторе виден значок ошибки PDF

### Requirement: Поделиться PDF
Пользователь SHALL иметь возможность отправить PDF тетради в другое приложение из редактора и из меню карточки в списке. Перед отправкой из редактора несохранённые изменения MUST сохраниться, и отправляется уже обновлённый файл.

#### Scenario: Отправка из редактора
- **WHEN** пользователь нарисовал штрих и сразу нажал «Поделиться PDF»
- **THEN** открывается системное окно «Поделиться», и отправленный PDF уже содержит этот штрих
