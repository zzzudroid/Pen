## Context

Тетрадь — холст со страницами одного размера и шаблоном (`notes`), экспорт PDF векторный (`pdf-export`). Мотивация — в `proposal.md`, требования — в `specs/pdf-annotate/spec.md`.

## Goals / Non-Goals

**Goals:** PDF — частный случай тетради, без отдельного движка; ввод не ждёт рендера подложки.

**Non-Goals:** векторное встраивание исходных страниц в экспорт (нужна PDF-библиотека), выделение текста PDF и «прилипающий» маркер, закладки и оглавление, формы PDF.

## Decisions

1. **Размер на странице, а не на тетради:** `PageState.spec` и `pdfPage`. `CanvasViewModel.pageSpec` — spec текущей страницы, иначе общий для тетради. Весь остальной холст (вписывание, границы пера, ластик, лассо) работает без изменений.
2. **`source.pdf` внутри `.pen`.** Тетрадь самодостаточна, её можно перенести на другой компьютер. Для `PdfRenderer` нужен файловый дескриптор с произвольным доступом, поэтому исходник извлекается в `cacheDir` и переиспользуется, пока `.pen` не новее.
3. **Формат v2:** `pageInfo` с размерами, шаблоном и `pdfPage` для каждой страницы. Поле `pages` остаётся. Чтение v1 — общий spec для всех страниц.
4. **Подложка — `PdfRenderer` → Bitmap, ступени ширины 512/1024/2048/4096, LRU около 96 МБ.** Нужная ступень = ширина листа на экране × плотность, округлённая вверх. Пока она рендерится, показывается лучший готовый битмап; по готовности — `onReady` → перерисовка. Один `PdfRenderer` на файл, под `Mutex`, на IO: `PdfRenderer` не потокобезопасен.
5. **Экспорт:** `PdfDocument` не умеет вставлять страницы другого PDF вектором, поэтому подложка — растр около 200 dpi, штрихи — векторные контуры поверх. Это компромисс по размеру файла; векторный перенос потребует PdfBox или pdfium (отдельное решение).
6. **Импорт через `ACTION_OPEN_DOCUMENT`**: на чтение выбранного файла разрешение не нужно. Байты копируются сразу, ссылка на исходник не хранится.
7. **Подагенты по слоям:** P1 — данные, формат, рендер и экспорт (`notes/*`, `Page.kt`, часть VM); P2 — интерфейс (подложка в `DrawingSurface`, кнопка импорта). P2 стартует после завершения UI лассо — оба правят `DrawingSurface`.

## Risks / Trade-offs

- [Большие PDF (сотни страниц, сканы)] → копирование `source.pdf` при каждом автосохранении. Для MVP допустимо, позже — не перепаковывать неизменённый источник.
- [Растровая подложка в экспорте увеличивает размер файла] → около 200 dpi, JPEG-сжатие внутри `PdfDocument` не контролируется; при жалобах на размер — ступень dpi в настройках.
- [Зашифрованные PDF] → `PdfRenderer` их не открывает: показываем понятную ошибку импорта.
