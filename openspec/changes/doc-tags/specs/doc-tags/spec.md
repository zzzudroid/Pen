## Purpose

Текстовые теги документов для быстрой пометки и отбора.

## ADDED Requirements

### Requirement: Теги документа
Документ SHALL хранить список текстовых тегов в `meta.json`. Тег MUST быть нормализован: без пробелов по краям и ведущих «#», не длиннее 24 символов; у документа не более 12 тегов; «Идеи» и «идеи» считаются одним тегом.

#### Scenario: Добавление дубля
- **WHEN** пользователь добавляет тег «идеи» документу, у которого уже есть «Идеи»
- **THEN** список тегов не меняется

#### Scenario: Старый файл
- **WHEN** открывается документ без поля `tags`
- **THEN** у него пустой список тегов и все штрихи на месте

### Requirement: Правка тегов
Пользователь SHALL менять теги из меню карточки и из редактора. Правка из списка MUST менять только метаданные файла и не затрагивать штрихи.

#### Scenario: Подсказки
- **WHEN** открыт диалог тегов
- **THEN** показаны теги других документов, которых ещё нет у этого, и они фильтруются по введённому тексту

### Requirement: Показ и фильтр
Теги SHALL показываться ярлыками на миниатюре (два первых и «+N»). В полных списках заметок и холстов SHALL быть фильтр по тегу с числом документов.

#### Scenario: Фильтр
- **WHEN** пользователь выбирает тег «идеи» в списке заметок
- **THEN** остаются только заметки с этим тегом; повторное нажатие или «Все» снимает фильтр
