## Context

Безграничный холст (`canvas-core`) и тетради с хранением (`notes`, формат v2 после `pdf-annotate`) уже есть. Мотивация — в `proposal.md`, требования — в `specs/board/spec.md`.

## Goals / Non-Goals

**Goals:** доска — тот же документ и тот же движок, без отдельного формата и экрана рисования.

**Non-Goals:** тайловый кэш для десятков тысяч штрихов, фигуры и коннекторы, стикеры, картинки, фреймы-презентации — отдельные changes.

## Decisions

1. **Доска = `.pen` с `kind: board` и одной страницей без границ** (размер 0×0 → `pageSpec == null`). Хранение, автосохранение, PDF, переименование, удаление и поиск по рукописи работают без отдельного кода. Старые файлы без `kind` — тетради.
2. **Вид сохраняется в `boardView`** (масштаб и сдвиг) и восстанавливается при открытии. Для доски `fitPage` ничего не делает, поэтому восстановленный вид не сбрасывается при первом измерении экрана.
3. **Экспорт по границам содержимого** (`StrokeOps.bounds` + 10 мм): одна страница PDF произвольного размера с векторными штрихами. Расчёт страницы — чистая функция с тестами.
4. **Мини-карта — отдельный слой в `DrawingSurface`**: масштаб по объединению границ содержимого и текущего вида, касание переносит центр вида. Касания мини-карты разбираются до маршрутизации пера и пальцев.
5. **Точечная сетка в мировых координатах с шагом 5 мм**; при сильном отдалении шаг удваивается, чтобы точки не сливались.
6. **Подагенты по слоям:** B1 (данные, `notes/*`) — сразу; B2 (интерфейс: список, редактор, мини-карта, сетка) — после завершения разметки PDF и поиска, которые сейчас правят `DrawingSurface`, экраны заметок и навигацию.

## Risks / Trade-offs

- [Производительность на больших досках] → полная перерисовка всех штрихов на каждый кадр жеста; при тысячах штрихов нужен тайловый кэш (отдельный change, в проектном документе он предусмотрен).
- [Очень большая страница PDF] → у PDF есть предел размера страницы (около 5 м); при превышении масштабируем содержимое под предел.
