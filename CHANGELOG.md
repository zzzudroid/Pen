# CHANGELOG

## 2026-10-05 — Первый запуск на Xiaomi Pad 7: диагностика пера

### Проверено на устройстве
- APK установлен и запускается на Pad 7 (HyperOS 3.0, **Android 16**, SDK 36), падений нет.
- Диагностика пера: давление ≈ 8192 уровня, наклон, азимут, hover, опрос ≈ 330 Гц (касание) / 200 Гц (hover).
  Отчёт — `docs/device/pen-diag-20261005.json`; выводы — `docs/design.md`, раздел 2.
- Тестовая зона: перо рисует с толщиной по давлению, палец не рисует; журнал `PenDiag` и JSON-отчёт работают.
- Сервисы Google на планшете есть — поиск по рукописи (ML Kit) возможен.

### Выяснено
- **Кнопка Focus Pen недоступна приложению**: HyperOS перехватывает её (частичный скриншот, плавающее окно Mi Canvas),
  события кнопки не приходят. «Временный ластик по кнопке» не работает; ластик — на панели инструментов.


## 2026-10-05 — Бесконечная доска (change `board`)

### Добавлено
- «Новая доска» в «Заметках»: документ `.pen` с `kind=board` в той же папке, значок доски в списке.
- Редактор доски: безграничный холст со всеми инструментами, автосохранение, восстановление последнего вида.
- Точечная сетка (шаг 5 мм, укрупняется при отдалении) и мини-карта с переходом по касанию.
- PDF доски — одна страница по границам содержимого с полями 10 мм; миниатюра вписывает содержимое.
- Переход из поиска по рукописи сразу на найденную страницу (`note/{id}?page=N`).


## 2026-10-05 — Поиск по рукописи (change `handwriting-search`)

### Добавлено
- Экран «Поиск по рукописи» на главном: запрос, обновление индекса с прогрессом и загрузкой модели,
  результаты «тетрадь · стр. N» с подсвеченным фрагментом; выбор открывает тетрадь.
- Распознавание русского рукописного текста ML Kit Digital Ink (на устройстве), разбиение страницы на строки.
- Индекс `filesDir/recognition/index.json`: распознаются только изменённые тетради, удалённые убираются.
- Поиск без учёта регистра и ё/е, все слова запроса на странице. JVM-тесты `LineSegmenter`, `TextSearch`.


## 2026-10-05 — Разметка PDF (change `pdf-annotate`)

### Добавлено
- «Открыть PDF» в «Заметках»: тетрадь из страниц PDF (размер каждой страницы — как в исходнике),
  исходный PDF хранится внутри `.pen` (`source.pdf`).
- Подложка страницы — растр PDF, рендер в фоне со ступенями 512–4096 px и LRU-кэшем; при зуме дорисовывается чётче.
- Все инструменты поверх PDF; можно добавлять обычные чистые страницы.
- Экспорт: подложка — растр исходной страницы ~200 dpi, штрихи — векторные.

### Изменено
- Формат `.pen` v2: `pageInfo` (размер, шаблон, `pdfPage` каждой страницы), `hasPdfSource`; v1 читается.
- `PageState` получил собственные `spec` и `pdfPage`; `CanvasViewModel.pageSpec` — размер текущей страницы.


## 2026-10-05 — Лассо (change `lasso`)

### Добавлено
- Инструмент «Лассо»: петля пером выделяет штрихи текущей страницы (≥ 50% точек внутри петли),
  пунктирная рамка с маркером масштаба.
- Перетаскивание выделения и равномерный масштаб (10–1000%, вместе с толщиной) с превью во время жеста.
- Панель действий: копировать (со сдвигом), удалить, перекрасить цветом палитры (выделитель сохраняет
  прозрачность), снять выделение.
- Команды истории `Replace` и `AddMany`: каждое действие лассо отменяется одним шагом; выделение
  снимается при отмене/повторе, стирании, смене страницы и инструмента.
- Чистая геометрия `Lasso.kt` (`Bounds`, `LassoPolygon`, `SelectionTransform`) с JVM-тестами, `StrokeOps`.


## 2026-10-05 — Экспорт PDF (change `pdf-export`)

### Добавлено
- Автоэкспорт: рядом с `<название>.pen` всегда свежий `<название>.pdf` — пересоздаётся при каждом сохранении
  и при создании тетради, переименовывается и удаляется вместе с ней.
- PDF векторный: штрихи — контуры Ink (`outlinesToPath`) с цветом и прозрачностью кисти, страницы A4 595×842 пт
  с шаблоном; атомарная запись.
- «Поделиться PDF» в редакторе (с сохранением и ожиданием записи перед отправкой) и в меню карточки тетради;
  `FileProvider`.
- Отдельный значок ошибки PDF в редакторе — сбой экспорта не мешает сохранению `.pen`.


## 2026-10-05 — Заметки (change `notes`)

### Добавлено
- Раздел «Заметки»: список тетрадей с миниатюрой первой страницы, числом страниц и датой изменения;
  создание (название + шаблон), переименование, удаление с подтверждением.
- Редактор тетради: страницы A4 с шаблонами «чистая», «линейка», «клетка», «точки»; переход между
  страницами, добавление и удаление страницы; история отмены — своя для каждой страницы.
- Автосохранение через 1,5 с после изменения, при выходе из редактора и сворачивании приложения;
  атомарная запись (временный файл → переименование).
- Формат `.pen` v1 — zip с `meta.json`, `pages/<id>.strokes` и `thumb.png`; хранилище `Documents/Pen/`.
- Разрешение `MANAGE_EXTERNAL_STORAGE` и экран-подсказка для его выдачи.
- JVM-тесты `FileNames` (очистка и уникальность имён файлов).

### Изменено
- Холст получил страницы (`PageState`, `PageSpec`): лист вписывается по ширине экрана, перо вне листа не рисует.
- Панель инструментов холста вынесена в общий `CanvasToolbar`.
- Новая зависимость `androidx.ink:ink-storage` 1.0.0.


## 2026-10-05 — Ядро холста (change `canvas-core`)

### Добавлено
- Экран «Холст»: рисование пером через androidx.ink 1.0.0 — активный штрих во фронт-буфере,
  предсказание движения (`input-motionprediction`), unbuffered dispatch для пера.
- Кисти «Ручка» (толщина по давлению), «Маркер», «Выделитель» (полупрозрачный), палитра из 6 цветов, 3 толщины.
- Штриховой ластик: инструмент на панели, `TOOL_TYPE_ERASER` и удержание кнопки пера
  (`BUTTON_STYLUS_PRIMARY|SECONDARY` — уточнить по отчёту диагностики).
- Отмена/повтор (кнопки и тап двумя/тремя пальцами); стирание одним движением — одна команда.
- Масштаб 25–3200% щипком и сдвиг пальцами, сброс вида кнопкой с текущим процентом.
- Защита от ладони: пальцы игнорируются, пока перо касается или висело над экраном < 500 мс назад;
  `ACTION_CANCEL` / `FLAG_CANCELED` отменяют штрих. Переключатель «Рисовать пальцем».
- Юнит-тесты `Viewport` и `History`.

### Изменено
- `androidx.core` 1.13.1 → 1.16.0 (транзитивно от Ink).
