# CHANGELOG

## 2026-10-05 — Заметки (change `notes`)

### Добавлено
- Раздел «Заметки»: список тетрадей с миниатюрой первой страницы, числом страниц и датой изменения;
  создание (название + шаблон), переименование, удаление с подтверждением.
- Редактор тетради: страницы A4 с шаблонами «чистая», «линейка», «клетка», «точки»; переход между
  страницами, добавление и удаление страницы; история отмены — своя для каждой страницы.
- Автосохранение через 1,5 с после изменения, при выходе из редактора и сворачивании приложения;
  атомарная запись (временный файл → переименование).
- Формат `.pen` v1 — zip с `meta.json`, `pages/<id>.strokes` и `thumb.png`; хранилище `Documents/Pen/`.
- Разрешение `MANAGE_EXTERNAL_STORAGE` и экран-подсказка для его выдачи.
- JVM-тесты `FileNames` (очистка и уникальность имён файлов).

### Изменено
- Холст получил страницы (`PageState`, `PageSpec`): лист вписывается по ширине экрана, перо вне листа не рисует.
- Панель инструментов холста вынесена в общий `CanvasToolbar`.
- Новая зависимость `androidx.ink:ink-storage` 1.0.0.


## 2026-10-05 — Ядро холста (change `canvas-core`)

### Добавлено
- Экран «Холст»: рисование пером через androidx.ink 1.0.0 — активный штрих во фронт-буфере,
  предсказание движения (`input-motionprediction`), unbuffered dispatch для пера.
- Кисти «Ручка» (толщина по давлению), «Маркер», «Выделитель» (полупрозрачный), палитра из 6 цветов, 3 толщины.
- Штриховой ластик: инструмент на панели, `TOOL_TYPE_ERASER` и удержание кнопки пера
  (`BUTTON_STYLUS_PRIMARY|SECONDARY` — уточнить по отчёту диагностики).
- Отмена/повтор (кнопки и тап двумя/тремя пальцами); стирание одним движением — одна команда.
- Масштаб 25–3200% щипком и сдвиг пальцами, сброс вида кнопкой с текущим процентом.
- Защита от ладони: пальцы игнорируются, пока перо касается или висело над экраном < 500 мс назад;
  `ACTION_CANCEL` / `FLAG_CANCELED` отменяют штрих. Переключатель «Рисовать пальцем».
- Юнит-тесты `Viewport` и `History`.

### Изменено
- `androidx.core` 1.13.1 → 1.16.0 (транзитивно от Ink).


## 2026-10-05 — Старт проекта: каркас и диагностика пера

### Добавлено
- Проектный документ `docs/design.md` (+ `.html`): цели, единый движок для четырёх режимов,
  стек, модель данных, этапы. Решения: первыми — заметки, приложение только для себя,
  доступ с ПК через открытую папку и автоэкспорт PDF (Syncthing — возможность на будущее).
- OpenSpec, change `stylus-diagnostics` (этап 0).
- Android-проект (AGP 8.7.2, Kotlin 2.0.21, Compose, SDK 35, пакет `com.zzzudroid.pen`).
- Экран «О программе»: версия, время сборки, git-хэш и пометка незакоммиченных изменений.
- Экран «Диагностика пера»: живые значения указателей (давление, наклон, азимут, кнопки,
  hover, устройство), сводка за сессию (диапазоны, уровни давления, частота событий,
  исторические точки), журнал событий, список устройств ввода с диапазонами осей,
  переключатель unbuffered dispatch, тестовая зона (перо рисует с толщиной по давлению,
  пальцы не рисуют), JSON-отчёт в `Documents/Pen/diagnostics/` + дамп в logcat (`PenDiag`).
- `tools/md2html.py` — сборка HTML-версий документов из Markdown.
