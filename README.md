# Pen

Личное Android-приложение для рукописного ввода стилусом на Xiaomi Pad 7 + Xiaomi Focus Pen:
заметки, разметка PDF, бесконечная доска, рисование. Проектный документ — [docs/design.md](docs/design.md).

Сейчас готово:
- **Полноэкранный режим** редактора — кнопка в правом верхнем углу: рабочая область на весь экран, слева тонкая плавающая
  панель инструментов (сворачивается).
- **Доска** — «Новая доска» в «Заметках»: бесконечный холст со всеми инструментами, точечная сетка, мини-карта
  (касание переносит вид), вид сохраняется; PDF — одна страница по границам содержимого.
- **Поиск по рукописи** — распознавание русского текста на устройстве (ML Kit, модель ~20 МБ скачивается один раз,
  нужны сервисы Google), индекс по страницам всех тетрадей, поиск без учёта регистра и ё/е.
- **Разметка PDF** — «Открыть PDF» в «Заметках» создаёт тетрадь из страниц PDF; поверх пишутся все инструменты,
  исходник хранится внутри тетради, экспорт — исходные страницы с пометками.
- **Лассо** (в «Холсте» и тетрадях) — выделить штрихи петлёй, перетащить, масштабировать маркером в углу,
  скопировать, удалить, перекрасить; всё отменяется.
- **Заметки** — тетради со страницами A4 и шаблонами (чистая, линейка, клетка, точки), все инструменты холста,
  автосохранение в `Documents/Pen/*.pen`.
- **Холст** — рисование пером с низкой задержкой (androidx.ink), ручка/маркер/выделитель, палитра,
  штриховой ластик, отмена/повтор, масштаб и сдвиг, защита от ладони.
  Палец не рисует: один палец — сдвиг, два — масштаб, тап двумя — отмена, тремя — повтор; переключатель «стирать пальцем»
  превращает палец в ластик. Панель инструментов — только значки. Холст — черновик: сохраняются только тетради.
- **Диагностика пера** — живые значения давления/наклона/кнопок/hover, сводка за сессию, тестовая зона и JSON-отчёт.
- «О программе» — версия, время сборки, git-хэш.

## Главный экран

При запуске — две половины: слева заметки (тетради), справа холсты (доски), превьюшки последних документов. Плитка «+» создаёт
документ сразу; заголовок половины («Заметки», «Холсты») открывает полный список. «О программе», «Диагностика пера», «Холст» и
«Поиск по рукописи» — в левой выезжающей панели (кнопка «Меню» в шапке).

## Каллиграфическое перо

Инструмент «Каллиграфия» на панели: плоское перо, толщина зависит от направления штриха и нажима. Сглаживание дрожания пера — кнопкой «волшебная палочка» на
панели инструментов (по умолчанию выключено), силу выбирают в настройках.

## Настройки

Боковое меню → «Настройки»: замочек по умолчанию в новых документах, шаблон новой заметки, цвет и толщина пера, стирание пальцем,
сетка и мини-карта досок, открытие ссылок тапом, «не гасить экран».

## Ссылки между документами

Обведи лассо нужное место → «Сделать ссылкой» → выбери документ (для доски — вид или закладку). Область ссылки подсвечена,
тап пальцем открывает цель, «Назад» возвращает. Ссылку можно изменить или удалить через то же выделение. Недоступная цель —
серая ссылка и сообщение «Документ недоступен». У доски есть закладки-места, у любого документа — панель «Откуда ссылаются».

## Требования

- JDK 17 (`JAVA_HOME`)
- Android SDK с platform 35 и build-tools 35
- `local.properties` в корне (не в git) с путём к SDK:

```properties
# Windows
sdk.dir=C:/Users/<user>/AppData/Local/Android/Sdk
# Linux
sdk.dir=/home/<user>/Android/Sdk
```

## Сборка и тесты

```bash
# Linux
./gradlew assembleDebug            # app/build/outputs/apk/debug/app-debug.apk
./gradlew testDebugUnitTest        # юнит-тесты (JVM)
```

```powershell
# Windows (PowerShell)
.\gradlew.bat assembleDebug
.\gradlew.bat testDebugUnitTest
```

## Установка на планшет

1. На планшете: «Настройки → О планшете» — 7 раз нажать на «Версия ОС», затем
   «Расширенные настройки → Для разработчиков» → включить «Отладка по USB»
   (на HyperOS также «Установка через USB»).
2. Подключить по USB и подтвердить отладку на планшете.
3. Установить:

```bash
adb devices                                            # планшет должен быть в списке
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

### Без провода (Wi‑Fi‑отладка)

1. «Для разработчиков → Отладка по Wi‑Fi» → «Подключить по коду».
2. На ПК: `adb pair <ip>:<порт-сопряжения>` и ввести код.
3. `adb connect <ip>:<порт>` (порт — с главного экрана «Отладка по Wi‑Fi»), дальше `adb install` как обычно.

## Диагностика пера

1. Открыть «Диагностика пера», провести штрихи от самого лёгкого до самого сильного нажима,
   наклонять перо, подержать его над экраном, понажимать кнопки.
2. Нажать «Сохранить отчёт» (иконка дискеты) — JSON ляжет в `Documents/Pen/diagnostics/`.
3. Забрать на ПК:

```bash
adb pull /sdcard/Documents/Pen/diagnostics/ .
```

Живой журнал событий: `adb logcat -s PenDiag` (движения пишутся с уровнем `V`, остальное — `D`).

## Тетради на ПК

1. При первом открытии «Заметок» выдать приложению «Доступ ко всем файлам» (кнопка на экране ведёт в настройки).
2. Тетради лежат в `/sdcard/Documents/Pen/*.pen`. Забрать на ПК:

```bash
adb pull /sdcard/Documents/Pen/ .
```

Рядом с каждой тетрадью лежит **`<название>.pdf`** — векторный PDF всех страниц, обновляется при каждом
автосохранении. Его можно сразу открыть на ПК; из приложения — «Поделиться PDF» в редакторе или в меню карточки.

`.pen` — обычный zip: `meta.json` (название, шаблон, страницы, даты), `thumb.png` (первая страница),
`pages/*.strokes` (штрихи).

## Release

Подпись release читается из `keystore.properties` в корне (в `.gitignore`):

```properties
storeFile=app/release.keystore
storePassword=...
keyAlias=pen
keyPassword=...
```

```bash
./gradlew assembleRelease
```
