Pen — проектный документ

Версия 0.2 · 2026-10-05 · статус: согласовано

Решения: первый режим — заметки · приложение только для себя (без магазина) · нужен доступ к заметкам с ПК (Windows и Linux).

1. Цель

Одно Android-приложение для Xiaomi Pad 7 + Xiaomi Focus Pen, которое закрывает четыре сценария:

  1. Рукописные заметки (тетради, страницы, разлиновка).
  2. Рисование и скетчинг (кисти с давлением/наклоном, слои).
  3. Разметка PDF (писать поверх, экспортировать обратно в PDF).
  4. Бесконечная доска (схемы, мозговые штурмы).

Главное требование ко всем четырём: перо должно ощущаться «как бумага» — минимальная задержка, точное давление, никаких случайных касаний ладонью.

3. Ключевая идея архитектуры: один движок — четыре режима

Все четыре сценария — это один и тот же холст со штрихами, отличаются только «подложкой» и границами:

Режим Границы Подложка Особенности
Заметки Страницы A4/A5 Чистая / линейка / клетка / точки Тетради, поиск по рукописи
Рисование Один лист произвольного размера Цвет / прозрачность Слои, кисти, режимы смешивания
PDF Страницы PDF Растр страницы PDF Экспорт аннотаций в PDF
Доска Без границ Сетка / пусто Тайлы, мини-карта, фигуры

Поэтому пишем один движок ввода/рендера/хранения и четыре тонких «оболочки» над ним.

5. Модель данных

Notebook (тетрадь/папка)
 └─ Document  { id, type: NOTES | DRAWING | PDF | BOARD, title, created, modified }
     └─ Page   { index, width, height (или ∞), background, pdfPageRef? }
         └─ Layer  { id, name, visible, opacity, blendMode }
             └─ Element
                  ├─ Stroke { brush, color, size, points: [x, y, t, pressure, tilt, orientation] }
                  ├─ Shape  { type, geometry, style }   — распознанные фигуры
                  ├─ Image  { uri, transform }
                  └─ Text   { content, font, transform }
  • Точки храним «сырыми» (с давлением и наклоном) — кисть можно поменять после рисования.
  • Каждое изменение — команда (AddStroke, Erase, Transform…) → бесконечный undo/redo и в будущем синхронизация через журнал операций.
  • Файл документа: document.pen = zip { meta.json, pages/*.pb, assets/*, thumb.png } — легко бэкапить и переносить.

Формат .pen v3 (реализовано; v1 и v2 читаются)

Единицы мира — 5 ед./мм; страница A4 (книжная) = 1050 × 1485.

<название>.pen  (zip, Documents/Pen/)
 ├─ meta.json            — formatVersion, title, template (blank|lined|grid|dots),
 │                         pageWidth, pageHeight, unitsPerMm, created, modified, pages: [id…],
 │                         pageInfo: [{id, width, height, template, pdfPage?}], hasPdfSource   (v2)
 │                         kind: notebook|board, boardView: {scale, tx, ty}   (доска: одна страница 0×0)
                         docId (UUID — постоянный идентификатор; у v1/v2 выводится из имени файла), v3:
                         links: [{id, pageId, rect, docId, bm?, view?}] — ссылки на другие документы,
                         bookmarks: [{id, name, view}] — закладки-места доски
 ├─ pages/<id>.strokes   — штрихи страницы (бинарный, DataOutputStream)
 ├─ source.pdf           — исходный PDF для тетрадей-разметок (v2, необязателен)
 └─ thumb.png            — миниатюра первой страницы, 300 px по ширине

Файл .strokes: int число штрихов; на каждый штрих — UTF id инструмента (pen / marker / highlighter), int цвет ARGB, float размер, float epsilon, int длина + байты StrokeInputBatch (androidx.ink.storage). Кисть хранится своими полями, а не сериализованной BrushFamily, — формат не зависит от внутреннего устройства стоковых кистей Ink. Запись атомарная: <имя>.pen.tmp → fsync → переименование.

Ссылки между документами: область ссылки (прямоугольник в мировых координатах страницы) хранит docId цели, а не имя файла, поэтому переименование цели ссылку не ломает. Цель — документ целиком, закладка доски или конкретный вид. Индекс filesDir/docindex.json (идентификатор → файл, закладки, исходящие ссылки) обновляется инкрементально по времени и размеру файла; из него же строятся обратные ссылки («Откуда ссылаются»). Недоступная цель — «Документ недоступен», ссылка рисуется серой.

6. Ввод и поведение пера

  1. Разделение инструментов: TOOL_TYPE_STYLUS рисует, TOOL_TYPE_FINGER — пан/зум/жесты, TOOL_TYPE_ERASER (если перо его отдаёт) — ластик.
  2. Защита от ладони: пока перо касается или висит над экраном (hover), пальцевые касания игнорируются; плюс обработка FLAG_CANCELED / ACTION_CANCEL для ложных касаний.
  3. Кнопки пера не используются — решение пользователя. Ни временный ластик, ни лассо, ни другие действия на кнопках в приложении не делаем (к тому же HyperOS перехватывает кнопку, см. раздел 2). Ластик и лассо — инструменты на панели.
  4. Hover: курсор-превью кисти (размер и цвет) над холстом.
  5. Жесты пальцами: 2 пальца — пан/зум/поворот, двойной тап двумя — undo, тремя — redo.
  6. Палец не рисует никогда. Переключатель «стирать пальцем»: включён — один палец работает как штриховой ластик, выключен — палец листает страницу (пан/зум), перо рисует.
  7. Полноэкранный режим редактора: рабочая область на весь экран, у левого края тонкая сворачиваемая плавающая панель инструментов.

7. Функции по режимам

Общее для всех: кисти (ручка, карандаш, маркер, перо-каллиграфия, кисть), палитра + пипетка, ластик (штриховой и пиксельный), лассо (переместить/масштабировать/копировать/перекрасить), undo/redo, зум до 3200%, экспорт PNG/PDF.

Заметки: тетради и папки, шаблоны страниц, вставка страниц, поиск по рукописи (ML Kit), конвертация рукописи в текст, распознавание фигур (удержать перо в конце штриха → ровная фигура).

Рисование: слои (до 32), режимы смешивания, прозрачность слоя, текстурные кисти, симметрия, референс-изображение.

PDF: открыть из файлов/«Поделиться», маркер «прилипает» к тексту (через текстовый слой, если есть), закладки, экспорт с аннотациями или отдельным слоем.

Доска: бесконечный холст, мини-карта, коннекторы между фигурами, стикеры, вставка картинок, фреймы для презентации.

10. Доступ с ПК

Приложение только для себя, поэтому без своего сервера и облака:

  1. Все документы лежат в открытой папке на планшете (Documents/Pen/), структура папок = структура тетрадей.
  2. Рядом с каждым .pen приложение автоматически держит свежий векторный .pdf (пересоздаётся при каждом сохранении, переименовывается и удаляется вместе с тетрадью; штрихи — контуры Ink, страницы A4 595×842 пт) — открывается на любом ПК без софта. Реализовано (change pdf-export).
  3. Забрать на ПК сейчас: USB (MTP) или adb pull /sdcard/Documents/Pen — одинаково на Windows и Linux.
  4. Формат .pen — открытый zip с protobuf + meta.json, поэтому позже можно сделать ПК-просмотрщик (этап 8) или импорт PDF/картинок с ПК через ту же папку.

Возможность на будущее (не в плане): автосинхронизация папки через Syncthing (P2P по локальной сети, Android + Windows + Linux). Архитектура к ней готова без доработок: хранилище — обычная папка с файлами, а копии конфликтов *.sync-conflict-* приложение должно будет показывать как отдельные документы. Включается одной настройкой Syncthing, код приложения менять почти не нужно.

11. Прочее

  • Только для себя → установка через adb install (USB или Wi‑Fi‑отладка), подпись личным ключом, никаких требований магазина; лицензии библиотек (PdfBox и т. п.) не ограничивают.
  • В меню «О программе» — версия, время сборки, git-хэш и пометка незакоммиченных изменений (как в VoiceTimer), чтобы по установленному APK сразу видеть свежесть билда.
  • Документация проекта: README.md (сборка/установка), CHANGELOG.md, CLAUDE.md; резервные копии установленных APK — в dist/ (не в git).
  • Отладка багов ввода — по logcat и диагностическому экрану, а не по догадкам.
  • Работа ведётся через OpenSpec: change stylus-diagnostics (этап 0) и canvas-core (этап 1).
