Главный экран

  1. [x] Новый главный вид при запуске. Экран делится пополам: левая половина — заметки (тетради), правая — холсты (доски), в каждой — превьюшки. Нынешний список из пяти пунктов (Заметки, Поиск по рукописи, Холст, Диагностика пера, О программе) уходит: «О программе», «Диагностика пера», «Холст», «Поиск по рукописи» — плоским текстом в шапке этого экрана. Главный экран грузится по умолчанию.
  2. [x] На главном — только последние. В каждой половине показываются несколько последних документов (не все). Полный список — отдельный экран, где видно всё: открывается тапом по заголовку половины («Заметки» / «Холсты»). Тап по превьюшке открывает сам документ.
  3. [x] Плитка «создать». Левая верхняя превьюшка в каждой половине — пустая, с плюсом: слева новая заметка, справа новый холст. Нажал — документ сразу создаётся и открывается, без диалога и захода в меню.

Допущения (поправь, если не так): - «холсты» справа = существующие доски; экран-черновик «Холст» остаётся ссылкой в шапке; - «при тапе … открывается там, где можно видеть все» понято как: тап по заголовку половины открывает полный список; - новая заметка создаётся без вопросов: имя — дата (дд.мм.гггг), шаблон страниц — «линейка»; доска — с именем-датой; - «Открыть PDF» — маленькая ссылка в заголовке левой половины (а не отдельная плитка); - карточки в половинах — те же, что сейчас (миниатюра, подпись, меню) с правками из пунктов 2–6.

Связи между заметками и холстами (решено: берём три варианта)

Выбраны А, Б, Г; В (плитка-ссылка с превью), Д (автоссылка по распознанному тексту) и Е (вырезка схемы в заметку) — отложены. Порядок работы: 13 → 11 → 10 → 12.

  1. [ ] Основа. Постоянный идентификатор документа в meta.json (сейчас id = имя файла, переименование ломало бы ссылки); список ссылок и закладок в файле — формат .pen v3 (v1/v2 читаются); поиск документа по идентификатору; ссылка на удалённый документ — видна как «недоступна», без падения.
  2. [ ] Закладки-места на доске (Б). На доске — «поставить закладку»: имя + текущий вид (место и масштаб). Список закладок доски; переход по закладке; переименование и удаление.
  3. [ ] Ссылка на выделенном (А). Обвёл лассо → «Сделать ссылкой» → выбор цели: документ (тетрадь/доска) и для доски — закладка или текущий вид. Область ссылки подсвечивается; тап пальцем открывает цель; «Назад» возвращает в исходное место. Править и удалять ссылку можно через лассо.
  4. [ ] Обратные ссылки (Г). Панель «Откуда ссылаются» у документа: в какой заметке/доске и на какой странице; тап ведёт к месту ссылки.

Не входит пока: плитка-ссылка с превью (В), автоссылки по распознанному тексту (Д), вырезка схемы в заметку (Е), кликабельные ссылки внутри экспортированного PDF.
