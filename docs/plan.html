План доработок

Список пунктов по ходу тестирования на планшете. Правило: пункты только записываются; реализация — по прямой команде («делай»). Статус: [ ] не сделано · [x] сделано.

Раздел «Заметки» (список)

  1. [x] Мини-карта доски — перенести из правого нижнего угла в левый верхний. Сделано раньше, чем появилось правило «сначала план»: коммит 1d5decb; ждёт проверки на планшете.
  2. [ ] Значок тетради на карточке. У доски на карточке есть значок доски — сделать такой же значок «тетрадь» у тетрадей, чтобы карточки были однотипными.
  3. [ ] Убрать слово «Доска» из подписи карточки: тип показывает значок, текст «Доска» не нужен.
  4. [ ] Формат даты на карточке — только цифрами через точку, без текста: дд.мм.гггг (сейчас «5 окт. 2026, 19:20»). Предположение: время не показываем (в запросе названы только число, месяц, год).

  5. [ ] Размер файла — показывать сверху на превьюшке (поверх миниатюры).

  6. [ ] Кнопки «Открыть PDF», «Новая доска», «Новая тетрадь» в списке заметок — сделать одинакового размера (сейчас разной ширины: подгоняются под длину подписи).

Главный экран

  1. [ ] Новый главный вид при запуске. Экран делится пополам: левая половина — заметки (тетради), правая — холсты (доски), в каждой — превьюшки. Нынешний список из пяти пунктов (Заметки, Поиск по рукописи, Холст, Диагностика пера, О программе) уходит: «О программе», «Диагностика пера», «Холст», «Поиск по рукописи» — плоским текстом в шапке этого экрана. Главный экран грузится по умолчанию.
  2. [ ] На главном — только последние. В каждой половине показываются несколько последних документов (не все). Полный список — отдельный экран, где видно всё: открывается тапом по заголовку половины («Заметки» / «Холсты»). Тап по превьюшке открывает сам документ.
  3. [ ] Плитка «создать». Левая верхняя превьюшка в каждой половине — пустая, с плюсом: слева новая заметка, справа новый холст. Нажал — документ сразу создаётся и открывается, без диалога и захода в меню.

Допущения (поправь, если не так): - «холсты» справа = существующие доски; экран-черновик «Холст» остаётся ссылкой в шапке; - «при тапе … открывается там, где можно видеть все» понято как: тап по заголовку половины открывает полный список; - новая заметка создаётся без вопросов: имя — дата (дд.мм.гггг), шаблон страниц — «линейка»; доска — с именем-датой; - «Открыть PDF» — маленькая ссылка в заголовке левой половины (а не отдельная плитка); - карточки в половинах — те же, что сейчас (миниатюра, подпись, меню) с правками из пунктов 2–6.
